Help & Docs

Quick Start (User)

  1. Choose Class name and Parts spec.
  2. Set matching config (property/sameAs, endpoint, mapping rules).
  3. Launch build and monitor in Jobs.
  4. Open build in History and inspect stats/files.
Detailed user tutorial: docs/user/tutorial.md

Quick Start (Admin)

Install and run:

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
bash scripts/run_server.sh
bash scripts/check_health.sh

Restart:

bash scripts/restart_server.sh
Detailed admin guide: docs/admin/setup_install_run.md
